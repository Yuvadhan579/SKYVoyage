# ✈️ SKYVoyage

A full-stack travel and aviation web application built with a modern TypeScript frontend and a dedicated backend server.

---

## 🛠️ Tech Stack

- **Frontend:** TypeScript, React / Vite, Tailwind CSS, PostCSS
- **Backend:** Node.js / Express (located in `/server`)
- **Tooling & Scripts:** Batch (`run.bat`, `start.bat`), PowerShell (`run.ps1`), Shell (`run.sh`)

---

```text
